# turtle-crossy-roads
A crossy roads game using Python Turtle

Features
- Arrow-key controlled turtle spawns at bottom of the screen.
- Moving cars are randomly generated as obstacles to the Turtle
- Once Turtle reaches top of screen, level is updated and speed of moving cars increases

Technologies
- Python
- Libraries: Turtle, Time, Random

What I Learned
- Using random generation to create cars
- Object oriented programming
- Arrow-key movement implementation
